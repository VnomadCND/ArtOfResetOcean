# CLAUDE.md: The Art of Reset Digital Edition

Read ROADMAP.md first. It is the full brief: experience, the eleven pages, architecture, file structure,
edition config, assets, phases and the release checklist. Then read reference/prototype/README.md.

## Working rules

1. Read `reference/prototype/ritual.html` and `feel.html` end to end before writing code. They are the spec for
   behaviour, timing and look. When ROADMAP.md and the prototype disagree on something visual, the prototype wins;
   ask Vernon about anything else.
2. Port first, improve second. Phase 1 is done when the new build is indistinguishable from the prototype, not
   better than it. Refactor into modules, but keep every number (timings, easing curves, shader constants, positions).
3. Keep the engine edition-agnostic: no page numbers, painting names or Ocean words in `src/`. If a page needs a new
   value, add it to `editions/<id>/edition.json` and to the schema.
4. One shader for the art. New effects (chop, cloud drift, soft focus, thread warp) are uniforms that default to off.
5. Vanilla TypeScript and Vite, no UI framework. Runtime dependencies: the PWA plugin and the fonts only.
6. Everything personal stays on the device (localStorage, wrapped in try/catch). Text from Release and
   Write in the sand is never stored.
7. Prototype quirks to fix, not copy: no draggable images in the stage (fixed in prototype Version 5), keep the
   `?page=` review jump for development builds only, and fit 11 recap rows on the keepsake (two columns).
8. Test each page with a Playwright walkthrough at 1440 x 900 and 390 x 780 and attach screenshots to each PR.
9. Do not commit 8000 px masters without Git LFS. `public/editions/` is generated by `scripts/build-assets.mjs`.
10. Ask before adding a new interaction type, changing the page rhythm, or changing any copy.
    Copy belongs to Vernon and Katherine.

## Start here (Phase 0)

- Scaffold Vite + TypeScript, vite-plugin-pwa, Playwright, @fontsource/cormorant-garamond, @fontsource/poppins.
- Write `scripts/build-assets.mjs` (sharp + ffmpeg): source/ masters -> public/editions/<id>/ (img 2560 + 1440 WebP,
  vid mp4 + webm, frame packs for fx-03 and fx-04, masks) and `scripts/check-assets.mjs` (missing files, sizes,
  first/last frame drift against the stills, edition.json schema).
- Gate: the Ocean edition builds from source/ with no errors.
